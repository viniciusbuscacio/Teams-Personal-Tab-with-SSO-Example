Privacy: educational template

This code receives an access token, validates it on the server, and displays the name and sign-in identifier when available. It does not store profiles or tokens in a database or write tokens to logs. The browser's token cache is kept in memory.

Sign-in uses Microsoft Entra ID and, within Teams, the Teams host. The hosting provider and these services may keep their own records. The operator must define appropriate contacts, purposes, retention periods, and policies before distributing the app. This page is not a final legal privacy policy.
